# Governance

ClawImaging is intended to be a consensus-driven open-source research software project.

## Roles

### Contributors
Anyone who contributes code, docs, benchmarks, datasets, review, design, or community support.

### Triage maintainers
People who help manage issues, labels, and contributor guidance.

### Core maintainers
People with merge responsibility for one or more subsystems.

### Steering group
A small group that resolves deadlocks, approves governance changes, and maintains strategic scope.

## Subsystem ownership

Expected initial ownership areas:

- Core / specs / artifacts
- CT / tomography
- MRI
- Coherent imaging
- Benchmarks / docs / community

## Proposal process

Use CIPs — Computational Imaging Proposals — for major changes involving:

- new modalities
- benchmark protocol changes
- artifact format changes
- dataset policy changes
- release policy changes

## Decision making

- Default: discussion and lazy consensus
- For major changes: explicit maintainer approval
- For deadlocks: steering-group decision after public discussion

## Values

- scientific honesty
- reproducibility
- openness
- explicit scope control
- respectful collaboration
