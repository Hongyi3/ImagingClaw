# LoDoPaB-CT

- Canonical name: `lodopab-ct`
- Version: `1.0`
- Modality: CT
- Measurement domain: sinogram
- Data kind: raw measurements
- Access: open
- Source: Leuschner et al., LoDoPaB-CT benchmark dataset for low-dose CT reconstruction
- Redistribution: follow upstream dataset terms; redistribute metadata and permitted artifacts only

## Notes

LoDoPaB-CT is the flagship open CT benchmark track for this repository. ClawImaging treats the
released sinograms and benchmark protocol as the measurement-domain source of truth for phase-1
benchmark validation.
