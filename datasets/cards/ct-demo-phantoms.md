# CT Demo Phantoms

- Canonical name: `ct-demo-phantoms`
- Version: `0.1`
- Modality: CT
- Measurement domain: sinogram
- Data kind: synthetic measurements
- Access: open
- Source: repository-local deterministic phantoms and proxy low-dose sinograms
- Redistribution: synthetic measurements and metadata may be shared with attribution

## Notes

This dataset is a smoke-test substrate for the Phase 2 CT workflow. It exists so demo runs and
declared example configs can validate against the dataset registry without implying that LoDoPaB
or other upstream benchmarks were executed directly.
