# MRI Demo K-Space

- Canonical name: `mri-demo-kspace`
- Version: `0.1`
- Modality: MRI
- Measurement domain: k-space
- Data kind: synthetic measurements
- Access: open
- Source: repository-local deterministic phantoms, coil maps, and undersampled multi-coil k-space
- Redistribution: synthetic measurements and metadata may be shared with attribution

## Notes

This dataset is a smoke-test substrate for the Phase 2 MRI workflow. It keeps demo runs and
declared example configs honest about using synthetic k-space rather than controlled-access
benchmark data.
