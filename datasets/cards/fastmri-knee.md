# fastMRI Knee

- Canonical name: `fastmri-knee`
- Version: `public-release`
- Modality: MRI
- Measurement domain: k-space
- Data kind: raw measurements
- Access: application-required
- Source: Zbontar et al., fastMRI: An Open Dataset and Benchmarks for Accelerated MRI
- Redistribution: raw measurements are not redistributed by this repository

## Notes

This registry entry tracks the controlled-access fastMRI knee benchmark used for accelerated MRI
reconstruction. Benchmark bundles must preserve the upstream access restrictions and record any
coil-handling or split assumptions explicitly.
