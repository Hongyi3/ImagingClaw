# Security Policy

## Scope

Please report security issues related to:

- arbitrary code execution
- unsafe command construction
- path traversal
- credential leakage
- insecure handling of restricted datasets
- unsafe defaults in artifact export

## Reporting

Until a dedicated security contact is configured, open a private security advisory on GitHub if
available. If private reporting is unavailable, contact the maintainers out of band and avoid
posting exploit details in a public issue first.

## Expectations

- Include reproduction steps
- Include affected files or commands
- Avoid accessing third-party systems or real private data
- Give maintainers a reasonable opportunity to patch before public disclosure
